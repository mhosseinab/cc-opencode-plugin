# Social preview

The [social preview image](assets/social-preview.jpg) is a 1280 × 640 JPEG version of the supplied landscape artwork, sized under GitHub's 1 MB limit. The README uses the same image.

## Configure GitHub

Committing an image or displaying it in the README does not configure GitHub's repository link preview. Upload the landscape image separately:

1. Open the repository's [**Settings**](https://github.com/mhosseinab/cc-opencode-plugin/settings).
2. Under **Social preview**, select **Edit → Upload an image…**.
3. Upload `docs/assets/social-preview.jpg` and save the preview.

GitHub accepts PNG, JPG, or GIF files under 1 MB and recommends 1280 × 640 pixels for best display. See [GitHub's social preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Refresh LinkedIn

After changing GitHub's preview, inspect `https://github.com/mhosseinab/cc-opencode-plugin` in [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/).

LinkedIn's refresh affects new posts; existing posts keep their previous preview. See [LinkedIn's cache refresh guidance](https://www.linkedin.com/help/linkedin/answer/a6269011).
